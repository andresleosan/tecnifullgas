# TecnifullGas

## Proyecto

Página de servicios de gas doméstico en Medellín y alrededores. Usa React 18,
TypeScript, Vite y Tailwind CSS; los recursos públicos están en `public/` y la
documentación del producto está en `docs/`.

## Trabajo

- Habla en español, salvo nombres de archivos y variables de código.
- Revisa la documentación pertinente antes de modificar funcionalidades.
- Conserva los cambios del usuario y las herramientas independientes del proyecto.
- Verifica los cambios con comandos reales e informa los resultados y limitaciones.
- Solicita confirmación explícita antes de desplegar a producción, aplicar
  migraciones destructivas o generar nuevos gastos.
- No incluyas secretos ni credenciales en el código o los registros.

## Comandos

- Desarrollo: `npm run dev`
- Compilación: `npm run build` (TypeScript, Vite, prerender y validación SEO)
- Lint: `npm run lint` (`eslint src --ext ts,tsx`)
- Vista previa: `npm run preview`

## graphify

Cuando el usuario escriba `/graphify`, usa la skill instalada `graphify` antes de
cualquier otra acción. Conserva sus herramientas y el conocimiento útil de
`graphify-out/`; actualiza el grafo cuando cambien sus fuentes.
